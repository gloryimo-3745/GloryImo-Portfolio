# Glory Imo Cybersecurity Portfolio

A responsive personal portfolio for Glory Imo, a Computer Technology senior at Bowie State University focused on cybersecurity, technology risk, network infrastructure, and IT support.

## Live website

[View the portfolio on GitHub Pages](https://gloryimo-3745.github.io/glory-imo-portfolio/)

## Features

- Responsive one-page portfolio for desktop, tablet, and mobile
- Home, About, Projects, Resume, and Contact sections
- Five interactive cybersecurity and infrastructure project cards
- Embedded and downloadable PDF resume
- QR code linking directly to the live GitHub Pages website
- GloryBot FAQ chatbot
- Contact form that prepares an email in the visitor's email application
- Accessible navigation, labels, keyboard controls, and reduced-motion support

## Chatbot implementation

GloryBot is implemented in vanilla JavaScript. It normalizes each visitor question, compares the words and phrases with defined intent groups, scores the possible matches, and returns the most relevant response.

The chatbot can answer questions about:

- Technical skills
- Education and expected graduation
- Academic experience
- Cybersecurity and infrastructure projects
- AI security and NIST AI RMF work
- Software security presentation
- Career interests
- Resume, GitHub, and contact information

Suggested questions and a fallback response are included to keep the conversation useful when a question does not match a known intent.
